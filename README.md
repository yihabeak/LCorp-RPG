# Vercel 배포 안내 — L사 지부 근무일지

Firebase 같은 외부 로그인 서비스는 쓰지 않는다. 로그인과 저장은 이 프로젝트 안의 Vercel 함수(`api/`)가 처리하고, 데이터는 Vercel에서 연결하는 Redis 저장소(Upstash)에 남는다.

## 폴더 구성

| 경로 | 하는 일 |
|---|---|
| `public/index.html` | 게임 전체 |
| `api/auth.js` | 아이디 가입, 로그인, 로그아웃, 로그인 상태 확인 |
| `api/slot.js` | 저장소 3칸 읽기·쓰기 (본인 것만) |
| `api/_lib.js` | 공용 도구: 저장소 호출, 비밀번호 해시, 로그인 유지 토큰, 시도 횟수 제한 |
| `vercel.json` | 출력 폴더와 헤더 |

저장소를 연결하지 않아도 사이트는 열린다. 그때는 비회원 플레이(기기 저장)만 된다.

---

## 1. Vercel에 올리기
1. 이 폴더를 GitHub 저장소로 올린다.
2. https://vercel.com/new 에서 저장소를 **Import**한다. Framework Preset은 **Other**로 두고 **Deploy**를 누른다.

## 2. 계정 저장소 연결 (한 번만)
1. Vercel 프로젝트 화면 → **Storage** 탭 → **Create Database**를 누른다. 목록에서 **Upstash(Redis)**를 고르고 무료 요금제로 만든다. 지역은 서울과 가까운 곳(예: 도쿄)을 고른다.
2. 만든 저장소를 이 프로젝트에 **Connect**한다. 접속 주소와 키가 환경 변수로 자동으로 들어온다.
3. **Deployments**에서 최신 배포의 **Redeploy**를 누른다. 환경 변수는 다시 배포해야 반영된다.

이제 타이틀 화면의 사원증 칸에 아이디 가입과 로그인이 나타난다.

> 코드는 환경 변수 `KV_REST_API_URL`·`KV_REST_API_TOKEN` 또는 `UPSTASH_REDIS_REST_URL`·`UPSTASH_REDIS_REST_TOKEN`을 읽는다. 연결했는데도 "계정 기능이 아직 준비되지 않았다"가 뜨면 Settings → Environment Variables에서 이 이름들이 있는지 확인한다. 없으면 Upstash 콘솔의 REST URL과 토큰을 이 이름으로 직접 넣고 다시 배포한다.

## 3. 내 컴퓨터에서 시험하기
```bash
npm i -g vercel
vercel link        # 이 폴더를 Vercel 프로젝트와 연결
vercel env pull    # 저장소 환경 변수를 받아 온다
npm run dev        # = vercel dev, http://localhost:3000
```
함수 없이 화면만 보려면 `npx serve public`을 쓴다. 이때는 비회원 플레이만 된다.

---

## 플레이어가 보는 것
- **비회원:** 바로 입사한다. 기록은 그 기기에만 남는다.
- **아이디 가입·로그인:** 아이디(영문 소문자·숫자·밑줄 4~16자)와 비밀번호(8자 이상)로 가입한다. 이메일은 받지 않는다.
- **저장소 3칸:** 칸마다 진행 기록과 도감 %를 따로 가진다. 진행은 30초마다, 그리고 화면을 벗어날 때 서버에 저장된다. 다른 기기에서 로그인하면 이어서 플레이할 수 있다.
- **비회원 기록 옮기기:** 로그인 후, 그 기기에 있던 비회원 기록을 원하는 칸으로 옮길 수 있다.

## 보안
- 비밀번호는 원문을 저장하지 않는다. scrypt로 해시한 값만 저장한다.
- 로그인 유지 토큰은 30일 동안 쓰지 않으면 끝난다. 서버에는 토큰을 해시한 값만 남긴다.
- 같은 주소에서 15분 동안 시도할 수 있는 횟수를 제한한다. 가입은 10번, 로그인은 30번까지다.
- 각 함수는 로그인한 본인의 저장소 칸만 읽고 쓴다.

## 비밀번호를 잊은 플레이어
이메일이 없으니 스스로 재설정할 수는 없다. 관리자가 Upstash 콘솔의 Data Browser에서 키 `u:아이디`를 지우면, 그 아이디로 다시 가입할 수 있다. 저장 기록(`s:아이디:1~3`)은 그대로 남아 이어진다. 그러니 키를 지우기 전에 본인인지 꼭 확인한다.

## 무료 한도
플레이 중에는 최대 30초에 한 번 저장한다. 한 사람이 한 시간 플레이하면 약 120회다. Upstash와 Vercel 함수에는 무료 사용량 한도가 있으니, 정확한 값은 두 서비스의 요금 페이지에서 확인한다. 플레이어가 많아지면 `public/index.html`의 `setInterval(flush74,30000)`에서 숫자를 늘린다(밀리초 단위).
